- (decision) AD-1: Adotado desacoplamento estrito API-First e Headless; PWA oficial e apps terceiros consom a mesma API pública.
- (decision) AD-2: Modelo P2P zero-custódia financeira; 100% dos pagamentos de turnos são diretos entre comerciante e entregador.
- (decision) AD-3: Subsistema de Delight Moments consome Chave PIX estática configurável via env sem gateway pago no MVP.
- (decision) AD-4: Motor de precificação regional implementado em PostgreSQL Views e Edge Functions com filtro 1.5xIQR e trava de velocidade de 30% em 12h.
- (decision) AD-5: Webhooks de saída assíncronos com assinatura HMAC-SHA256 e retentativas com backoff exponencial.
- (decision) AD-6: Stack de comunicação com custo zero operacional usando FCM Web Push, Supabase Realtime Channels e In-App Inbox.
- (decision) AD-7: Autenticação passwordless por Magic Link com JWT persistente em IndexedDB.
- (decision) AD-8: Estrutura geográfica universal (state_id, city_id, neighborhood_id) cobrindo todo o território nacional desde a Sprint 1.
- (decision) AD-9: Web Component <delivrery-button /> distribuído em Vanilla JS sem dependência de frameworks.
- (decision) AD-10: Segurança com Row Level Security (RLS) obrigatória em todas as tabelas do PostgreSQL.
- (event) Architecture Spine criado e sincronizado com os FRs do PRD.
